🩺 「测试连接」没通？按状态码一眼定位

现在测试失败会直接显示 HTTP 状态码 + 服务端原文，不再一句笼统的「没通」。对照下表处理：
401 + bind / Alibaba Cloud账号没绑定阿里云或未实名 → 去账号设置绑定并实名，等 1~3 分钟，必要时重新生成 Token
401 其它 / Invalid tokenToken 复制不全、过期或权限没勾 → 回 modelscope.cn/my/myaccesstoken 重复制完整 ms- 串
403 + email verification / Magicubes最常见：邮箱没验证。魔搭规定「邮箱验证通过」才开放魔粒 / API-Inference → 去 modelscope.cn/my/settings/account 点「验证邮箱」，到邮箱（含垃圾箱）点链接，回来确认已验证；顺手把「身份」也选一下并保存。一般不用换 Token
403 + real name verified阿里云账号未完成实名认证 → 完成实名后等几分钟，用同一个 Token 重试
400 / 404 ModelNotFound模型 id 不在当前清单 → 点「🔎 查当前可用模型」从官方清单里挑一个，或点「⭐ 推荐模型」换
429限流或当天魔粒用完 → 等一会儿 / 明天再试，换轻量模型
网络错误 / 无状态码浏览器跨域预检被拦或网络不通 → 先点「🔎 查当前可用模型」判定（它不要 Token）；不通就走本地桥
HTTP 200 但无内容挂牌模型或思考型模型 → 换一个 id 再测
5xx魔搭服务端临时故障 → 稍后重试，不是你的配置问题
顺序建议：先看 Key 框旁边的格式自检 → 点「🔎 查当前可用模型」确认网络与真实 id → 再点「🧪 测试连接」。三步就能把「地址 / 网络」「Token / 账号」「模型名」彻底分开。
账号三道关，别混淆：① 绑定阿里云账号　② 阿里云实名认证　③ 邮箱验证通过。前两关过了也可能卡在第 ③ 关——魔搭官方《Magicube Rewards Program》明确写「使用魔粒的前置条件是完善个人信息且邮箱验证通过」，而 API-Inference 用魔粒结算，所以邮箱没验证会直接 403。账号设置页里邮箱旁边还显示「验证邮箱」几个字，就说明没验证完。

🛠 本地桥（可选）· 最省额度、Key 不进浏览器

先看这里：你真的需要它吗？

· 不开 AI → 整块都不用看，直接关掉这个页面去玩就行。
· 开了 AI，而且「🧪 测试连接」显示「✅ 通了」 → 也不用看，已经能用。
· 只有两种情况才往下看：测试连接没通、提示跨域被拦；或者网站已经部署到 https 上，你想用自己电脑上的桥。
下面那一大段代码，你一个字都不用看懂，也不用改。它只是个「传话员」：浏览器只跟自己电脑里的传话员说话（这个允许），传话员再替你去问魔搭，把答案带回来。令牌也只交给传话员，不进浏览器。你要做的只是把它下载下来、跑起来。

照着做三步（电脑需要有 Python；Windows 可在微软商店搜「Python」安装，Mac 一般自带）

第 1 步　点这个按钮 → （页面最下面也有一个，点哪个都行）。文件会存到「下载」文件夹，不用打开、不用编辑。
第 2 步　打开命令行，进入「下载」文件夹，粘贴下面其中一行后按回车：
Windows PowerShell：
cd $env:USERPROFILE\Downloads
$env:MODELSCOPE_TOKEN="ms-你的令牌"; python bridge.py

Mac / Linux：
cd ~/Downloads
MODELSCOPE_TOKEN=ms-你的令牌 python3 bridge.py
看到 bridge  ->  http://localhost:8787/v1/chat/completions 就成了。这个黑窗口不要关，关了桥就停了。
第 3 步　回到本页：上面「免费通道」选「本地桥 / Cloudflare Quick Tunnel」，接口地址会自动填好 → 勾「开启 AI 增强」→ 点「💾 保存设置」→ 点「🧪 测试连接」→ 出现「✅ 通了」就完成。之后回成语接龙，卡住时点「🤖 让 AI 帮我想一个」。
小提醒：黑窗口关掉、电脑重启后要再跑一次第 2 步；那串 ms- 令牌只敲在命令行里，不会存进浏览器。如果网站已经部署到 https，第 2 步之后还要再开一个窗口跑 cloudflared tunnel --url http://localhost:8787，把打印出来的 https 地址加上 /v1/chat/completions 填进「接口地址」（因为 https 页面不能连 http 地址）。
不想碰命令行？改用「Puter.js」零配置通道，或直接在魔搭通道里填令牌，通常更省事。
下面是给想自己改代码的人看的原始脚本（零基础用户照上面三步做即可，不用读它）。它只用 Python 标准库、无需 pip，给魔搭（或你自己的 Ollama）加一层 CORS 头，页面就能跨域调用； Token 放在本机环境变量里，不会出现在浏览器或 localStorage。本机双击打开页面时用 http://localhost:8787/v1/chat/completions； 如果页面挂在 HTTPS 站点上、或想在手机上用，再用 Cloudflare Quick Tunnel 把 8787 映射成临时 https 地址，填进上面的「接口地址」即可。 
# -*- coding: utf-8 -*-
# 趣学益智馆 · 极简本地桥（仅标准库）
# 1) MODELSCOPE_TOKEN=ms-你的令牌 python3 bridge.py
#    （本机页面填 http://localhost:8787/v1/chat/completions）
# 2) 想跨设备 / HTTPS 页面再开一条：
#    cloudflared tunnel --url http://localhost:8787
#    把打印出的 https://xxx.trycloudflare.com 加上 /v1/chat/completions 填进页面
import os, json, urllib.request
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

# 也可改用本机 Ollama：UPSTREAM=http://localhost:11434/v1/chat/completions
UPSTREAM = os.environ.get("UPSTREAM", "https://api-inference.modelscope.cn/v1/chat/completions")
TOKEN = os.environ.get("MODELSCOPE_TOKEN", "")

class H(BaseHTTPRequestHandler):
    def cors(self):
        self.send_header("Access-Control-Allow-Origin", "*")
        self.send_header("Access-Control-Allow-Headers", "Content-Type, Authorization")
        self.send_header("Access-Control-Allow-Methods", "POST, OPTIONS")
    def do_OPTIONS(self):
        self.send_response(204); self.cors(); self.end_headers()
    def do_POST(self):
        body = self.rfile.read(int(self.headers.get("Content-Length", 0)))
        headers = {"Content-Type": "application/json"}
        if TOKEN: headers["Authorization"] = "Bearer " + TOKEN
        req = urllib.request.Request(UPSTREAM, data=body, headers=headers, method="POST")
        try:
            with urllib.request.urlopen(req, timeout=30) as r: out, code = r.read(), 200
        except Exception as e:
            out, code = json.dumps({"error": str(e)}).encode(), 502
        self.send_response(code); self.cors()
        self.send_header("Content-Type", "application/json")
        self.end_headers(); self.wfile.write(out)
    def log_message(self, *a): pass

print("bridge  ->  http://localhost:8787/v1/chat/completions")
print("跨设备  ->  cloudflared tunnel --url http://localhost:8787")
ThreadingHTTPServer(("127.0.0.1", 8787), H).serve_forever()
关于 Quick Tunnel（官方口径）：它不是 AI API，只是把本机端口发布成一个随机的 trycloudflare.com HTTPS 地址；无需 Cloudflare 账号、无需域名、不收费。限制是：仅用于测试开发、无可用性保证、 单隧道最多 200 并发、不支持 SSE、每次创建域名都会变、进程退出即失效，且默认任何拿到链接的人都能访问（新版可用 --allowed-mail 加邮箱验证）。所以它只解决「HTTPS 页面 / 跨设备访问本机桥」，推理仍来自桥后面的魔搭或 Ollama。

📚 这轮查到的资料与方案取舍（截至 2026-11-07）

魔搭 ModelScope API-Inference · 官方免费、OpenAI 兼容 api-inference.modelscope.cn/v1； 前提是绑定阿里云账号并完成实名认证。额度按「魔粒」扣减（轻量 0.5 / 主流 1 / 旗舰 2 每次）且会按平台压力动态调整， 官方未承诺固定每日次数，网上流传的「2000 次/天」不是官方口径。社区有浏览器直连成功、服务端返回 Access-Control-Allow-Origin: * 的报告；本页开发环境出网被网关拦截、无法替你实测预检，请以「测试连接」为准。 → 采纳为默认通道。
Cloudflare Quick Tunnels · 免费、无需账号/域名，一条命令把本地服务映射成临时公网 URL； 无 SLA、200 并发上限、不支持 SSE、域名每次变、仅测试开发用途。它不是 AI API、不提供任何模型推理。 → 采纳为本地桥的跨设备/HTTPS 可选一步，不作为推理来源。
Cloudflare Workers AI · 免费层每天 10,000 Neurons、无需信用卡；但需 Cloudflare 账号 + Account ID + 带 Workers AI Read 权限的 Token，REST 端点要拼 account_id，且国内直连不稳。 → 不预置成通道，需要时填进「自定义 OpenAI 兼容端点」。
Puter.js · 一个 script 标签 + puter.ai.chat()，无需 Key、无需填地址，采用 User-Pays （费用记在使用者自己的 Puter 账户，可能需要登录）。→ 采纳为「零配置」实验通道，且只在选中并开启后才动态加载脚本，默认零联网。
Google Gemini 免费层 · 无需信用卡、CORS 预检允许浏览器直连，但国内网络通常不可达； 智谱 GLM-4-Flash 长期免费、国内直连较稳；Pollinations 免注册但匿名限流约 30 秒一次。 → 三条保留为备选，按你的网络环境挑。
以上均为第三方服务，免费条款、模型 id 与限流随时会变，以其官网最新说明为准；本页不含任何密钥，也不替你保管额度。AI 只用于「帮想候选」和可选的释义补全，判对错始终由本地规则完成。
